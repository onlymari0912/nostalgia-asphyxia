# nostalgia@asphyxia

NOSTALGIA OP3 plugin for Asphyxia CORE.

Registered routes:
- `op3_common.get_common_info`
- `op3_common.get_music_info`
- `op3_player.regist_playdata`
- `op3_player.get_musicdata`
- `op3_player.get_playdata`
- `op3_player.set_stage_result`
- `op3_player.set_total_result`


## Notes
The plugin directory requires `music_list.json`. This file is needed for song jackets to display correctly.  
Convert `data_op3/sound/music_list.xml` to JSON with jsutil before using it.
